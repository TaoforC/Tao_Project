From 2026-11-14 to 2026-11-22, over the course of one week (weekends and weekday evenings), I completed the design of my own Snake game 1.0, as a milestone validation of my C++ learning. I didn't want the hassle of splitting it into multiple .cpp and .h files, so it's all in a single main.cpp.

Earlier on, I had downloaded a Snake game from GitHub and studied it carefully. This time, though, I designed the game myself. I did reference other people's design ideas, but I still ran into all kinds of difficulties, and went through repeated debugging of results and some hard thinking.

Along the way, I also made some use of AI-assisted programming. Through DeepSeek, I learned about the mt19937 algorithm for generating random numbers, the function for moving the cursor, the function for hiding the cursor, and the fact that each of the up/down/left/right arrow keys is a two-byte extended key, along with how to retrieve the corresponding parameters. In addition, during debugging, I encountered all sorts of strange results, most of them I solved through my own independent thinking, and a few I consulted DeepSeek about.

Overall, I'd say this counts as a result of doing my best to think independently and sticking to manual programming. My next goal is to move on to learning Python and VBA, so GOOD BYE C++, I will get back to you someday.
